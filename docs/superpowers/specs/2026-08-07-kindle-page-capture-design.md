# KindleページキャプチャPDF化ツール 設計仕様

## 目的

macOS上のKindleアプリで現在表示されているページを自動取得し、ページ送りと画面キャプチャを繰り返して画像PDFを作成する。

Kindle内部ファイルの読み出し、DRMの解除、暗号化データの復号は行わない。

## 対象範囲

### 対象にする機能

- macOS上で動くコマンドラインツール
- Kindleアプリの対象ウィンドウを検出して選択する
- 現在表示されているページから指定ページ数を取得する
- Accessibility API経由で次ページへ移動する
- ウィンドウ画像を取得する
- 画面変化と描画完了を確認してから次の画像を保存する
- 取得画像を1つの画像PDFへまとめる
- 途中停止、進捗保存、同じセッションの再開
- Accessibility権限とScreen Recording権限の事前確認
- 別デスクトップまたは別ディスプレイに配置したKindleウィンドウを対象にする

### 対象にしない機能

- Kindleファイル（`.kfx`、`.azw`など）の直接解析
- DRMの判定や解除
- Kindleアプリの認証情報やライセンス情報の取得
- 仮想ディスプレイの作成
- OCR、テキスト検索可能PDF、翻訳、再レイアウト
- Kindleアプリが最小化・非表示の状態での動作保証

## 利用者向けインターフェース

最初の実装はCLIとする。利用者はKindleアプリで本を開き、最初に取得したいページを表示してからコマンドを実行する。

```bash
kindle-to-pdf capture --output book.pdf --pages 200
```

オプションは次のとおりとする。

- `--output <path>`: 出力PDFのパス。必須
- `--pages <count>`: 取得ページ数。必須。現在表示中のページを1ページ目として数える
- `--window <title>`: 対象Kindleウィンドウのタイトル。省略時はKindleウィンドウを検出する
- `--next-key <right|pagedown>`: ページ送りキー。省略時は`right`を使う
- `--session <path>`: セッションディレクトリ。省略時は出力PDFの隣に`<stem>.kindle-session`を作る
- `--resume`: 指定または自動決定したセッションを読み込み、保存済みページの続きから再開する
- `--overwrite`: 完成済みPDFを上書きする。指定しない場合は開始前に終了する

Kindleウィンドウが複数ある場合は、候補を表示して開始前に選択させる。対象ウィンドウを一意に特定できない場合は処理を開始しない。

## 実行フロー

1. CLI引数を検証する。
2. 出力PDFとセッションディレクトリの既存状態を確認する。
3. `--resume`がなければ新しいセッションを作成し、既存の未完了セッションがあれば開始前に終了する。`--resume`があれば状態と保存画像を検証する。
4. 完成済みPDFが存在する場合、`--overwrite`がなければ開始前に終了する。
5. Accessibility権限とScreen Recording権限を確認する。権限不足なら操作を開始せず、必要な設定画面を案内する。
6. Kindleアプリの対象ウィンドウを検出し、ウィンドウIDとプロセスIDを保持する。
7. 新規セッションでは対象ウィンドウの現在画像を取得し、最初のページとして保存する。再開時は保存済みページ数を確認し、その続きから開始する。
8. 指定ページ数に達していなければ、対象プロセスへ次ページキーを送る。
9. 画像が前回と変化し、かつ連続したサンプルで安定するまで待つ。
10. 次のページ画像を保存し、セッション状態を更新する。
11. 8から10を指定ページ数まで繰り返す。
12. 保存済み画像をページ順にPDFへ変換する。
13. PDFの書き込みが完了したらセッション状態を完了に更新する。

ページ変化の確認は、ウィンドウ画像を比較して行う。描画待機には上限時間を設け、上限を超えて変化しない場合は重複ページを追加せず停止する。

Kindleウィンドウは最小化せず、別デスクトップまたは別ディスプレイに配置することを前提とする。ウィンドウ画像を取得できない場合は、PDFを完成扱いにせずエラーとして停止する。

## コンポーネント

### WindowLocator

macOSのウィンドウ一覧からKindleアプリのウィンドウを検出する。タイトル指定があれば一致するものだけを候補にする。後続処理にウィンドウID、プロセスID、表示領域を渡す。

### PageTurner

Accessibility APIを使って対象Kindleプロセスへ次ページ操作を送る。デフォルトは右矢印キーとし、CLIでPageDownへ変更できる。操作結果だけではページ遷移を保証できないため、遷移の成否はPageStabilityCheckerが画像差分で判定する。

### PageCapture

対象ウィンドウの画像をウィンドウ単位で取得する。四隅から均一と判断できる外周背景の余白は自動で除去するが、ページ内部の余白は保持する。外周背景を確実に判定できない画像は変更せず保存する。

### PageStabilityChecker

ページ送り前後の画像を比較し、画面が変化したことと描画が安定したことを判定する。判定に失敗した場合は一定回数の再試行後にセッションを停止する。失敗時の画像はページとして採用しない。

### SessionStore

セッションディレクトリにページ画像とJSON状態を保存する。状態には出力先、取得予定ページ数、取得済みページ数、対象ウィンドウの識別情報、最終保存画像のハッシュ、セッション状態を含める。

```text
book.pdf
book.kindle-session/
  state.json
  pages/
    0001.png
    0002.png
```

再開時は同じKindle本を同じページ位置で開いていることを利用者の責任とする。ツールはKindle本のタイトルや実ページ番号を取得して照合しない。

### PDFWriter

セッションディレクトリの画像を自然順に読み込み、各画像のピクセル比率を保ったPDFページを作成する。PDFは画像PDFとし、画像のページ順と欠落を検証してから出力する。

## 停止と再開

- `Ctrl-C`を受けた場合、現在のページ取得処理を安全に終了し、保存済みページを残す
- ページ取得後に必ず状態を書き込むため、再開時は最後に完全保存されたページの次から続ける
- 出力PDFが未完成の場合は、再開時にセッション画像から作り直す
- 既存の完成PDFを無確認で上書きしない
- セッション状態が完了済みの場合は、再実行前に明示的な上書き指定を要求する

再開コマンドは次の形式とする。

```bash
kindle-to-pdf capture --output book.pdf --pages 200 --resume
```

## エラー方針

- Kindleアプリが見つからない場合は、アプリを起動せず終了する
- 対象ウィンドウを特定できない場合は、候補を表示して終了する
- 権限不足の場合は、必要な権限名とmacOS設定の場所を表示する
- ウィンドウ画像を取得できない場合は、画像を保存せず終了する
- ページ変化を検出できない場合は、重複ページを保存せず終了する
- 破損または欠落したセッション画像がある場合は、PDF作成前に終了する
- PDF作成に失敗した場合は、セッション画像と状態を保持する

すべての処理はローカルで完結し、ネットワーク通信は行わない。

## テスト方針

macOS APIを直接呼び出す部分と、純粋な処理を分離する。

自動テストの対象は次のとおりとする。

- CLI引数が不足・不正な場合のエラー
- セッション状態の保存と読み込み
- ページ番号の自然順ソート
- 画像差分による変化・安定判定
- 途中停止後の再開位置
- 画像からPDFへの変換
- 欠落・破損画像がある場合のPDF生成拒否
- 完成済みPDFの無確認上書き拒否
- `--resume`なしで未完了セッションを再利用しないこと
- `--resume`で保存済みページ数の次から開始すること
- `--overwrite`なしで完成済みPDFを変更しないこと

Kindleアプリ、Accessibility API、Screen Recording APIを使う結合確認はmacOS上で手動実行する。手動確認では、別デスクトップでの実行、Kindleウィンドウの最小化、権限不足、ページ遷移失敗、途中停止と再開を確認する。

## 技術選定

- 言語: Swift
- 実行形式: Swift Package Managerの実行ターゲット
- ウィンドウ列挙・画像取得: macOSのWindowServer API
- ページ送り: macOS Accessibility API
- PDF生成: macOS標準のPDF API
- テスト: XCTest
- 外部ライブラリ: 初期版では使用しない

## 完了条件

- macOSでCLIをビルドできる
- Kindleウィンドウを指定または選択できる
- 現在ページから指定ページ数の画像を取得できる
- 取得画像を正しい順序のPDFにできる
- ページ変化を検出できない場合に重複ページを追加しない
- Ctrl-C後に同じセッションを再開できる
- 権限不足やウィンドウ取得失敗を明確に報告できる
- 別デスクトップまたは別ディスプレイに置いたKindleで、別作業と並行して動作することを手動確認できる
